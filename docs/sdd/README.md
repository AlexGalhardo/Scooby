# SDDs — especificações e desenho de software

SDD neste projeto significa **Software Design Document**, usado como especificação
para implementação e verificação. Cada SDD descreve comportamento, contratos,
falhas, critérios de aceite e pendências. Não é código já implementado.

| ID | Documento | Estado |
| --- | --- | --- |
| SDD-01 | [Identidade e dashboard](01-identidade-dashboard.md) | Requisitos confirmados; detalhes propostos |
| SDD-02 | [Dados e estratégias](02-dados-estrategias.md) | Mercados confirmados; feeds e parâmetros pendentes |
| SDD-03 | [Risco e execução](03-risco-execucao.md) | Paper confirmado; políticas e desenho propostos |
| SDD-04 | [Backtesting](04-backtesting.md) | Proposto |
| SDD-05 | [Railway e operação](05-operacao-railway.md) | Destino confirmado; desenho proposto |
| SDD-06 | [Adapters e simulação](06-adapters-simulacao.md) | Adapters confirmados; dados pendentes |

Alterar um contrato exige revisar ADR associado, modelo de dados, plano e testes.
